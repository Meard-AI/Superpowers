## How to Use / Install on Any Computer

1. **Portability**: Simply copy any skill folder (e.g. `ultra-instinct`) to any machine's agent skill directory:
   - Antigravity / OpenCode Workspace: `<workspace_root>/.agents/skills/`
   - Global Config: `~/.gemini/config/skills/` or `~/.claude/skills/`

2. **Requirements**: Python 3.8+ (Uses standard library modules only; zero external `pip` dependencies).
