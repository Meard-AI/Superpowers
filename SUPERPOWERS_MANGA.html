A minimalist reference for high-performance agent architecture. Single-word, zero-dependency tools designed for instant reflexes, path containment, and self-healing autonomy.

ACT 01 // WARP

warp

"Bypass the 20-Second Pause. Execute Routine Tasks Instantly."

Intercepts simple subtasks (like status checks, formatting, or directory listing) and executes them deterministically in under 10 milliseconds via local pattern matching—skipping heavy LLM reasoning loops entirely.

TACTICAL OUTCOME
  • 70% reduction in LLM token expenditure
  • Sub-10ms response time on routine terminal checks
  • Automatic escalation to deep reasoning models when queries grow complex
python3 scripts/reflex_router.py --query "git status" --json
ACT 02 // CLONE

clone

"Observe Once. Replicate Forever."

Parses raw execution transcripts, terminal session logs, or API traces and automatically packages them into parameterised, reusable custom agent skills.

TACTICAL OUTCOME
  • Zero-code skill generation in under 3 seconds
  • Eliminates prompt drift across multi-step commands
  • Instant portability across any local or remote agent workspace
python3 scripts/trajectory_cloner.py --log trace.log --name deploy-prod --json
ACT 03 // FENCE

fence

"Strict Air-Gapped Path Containment."

Calculates absolute canonical paths using realpath resolution and verifies file mutations against target root boundaries—hard-blocking unauthorized directory escapes.

TACTICAL OUTCOME
  • 100% boundary safety against accidental file overrides or path traversal
  • Total isolation when running agents on production repositories
  • Hard security block triggered prior to tool execution
python3 scripts/sandbox_enforcer.py --path "src/app.js" --allowed-root "/project" --json
ACT 04 // GEAR

gear

"Shift Operating Gears Mid-Flight."

Dynamically adapts system prompts, token budgets, and allowed toolsets based on the current project phase (plan → build → audit → format).

TACTICAL OUTCOME
  • Prevents context pollution by isolating active stage instructions
  • Caps token budgets per phase to minimize context bloat
  • Restricts write tools during audit or design phases
python3 scripts/context_adapter.py --stage audit --json
ACT 05 // RESCUE

rescue

"Break Infinite Apology and Failure Loops."

Monitors command streams for repetitive error patterns. When an agent stalls, it forces a self-healing protocol—relaxing strict schemas and executing diagnostic fallbacks.

TACTICAL OUTCOME
  • Automatically breaks agent retry loops without human intervention
  • Executes alternative CLI diagnostics to isolate root causes
  • Guarantees long-running background agent tasks complete overnight
python3 scripts/anti_stall.py --error-log "Build failed" --consecutive-failures 3 --json
ACT 06 // JAIL

jail

"High-Speed Refactoring Inside a Locked Sub-Zone."

Grants agents high-frequency file editing privileges strictly inside a designated subdirectory while enforcing real-time perimeter checks on all subshell commands.

TACTICAL OUTCOME
  • Fast-path file refactoring inside isolated target folders
  • Zero side-effect leakage to git roots or parent environments
  • Clean subshell execution with structured JSON telemetry
python3 scripts/cqc_executor.py --perimeter-dir "/project/src" --cmd "npm test" --json
ACT 07 // FUZZ

fuzz

"Genetic Payload Mutation & Bug Hunting."

Applies 5 genetic mutations (null byte injections, extreme unicode, format strings, boundary numbers) to code snippets or API payloads to uncover hidden crashes before production.

TACTICAL OUTCOME
  • Discovers boundary bugs and crash vectors missed by standard generation
  • Validates software resilience against corrupted inputs
  • Outputs instant vulnerability risk scores and crash logs
python3 scripts/mutation_fuzzer.py --target "function parse(x) { ... }" --mutations 5 --json
